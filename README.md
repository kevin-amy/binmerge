# binmerge
2个bin文件合并工具，其中第1个bin文件4K空间，不足4K填充0xff

## 核心功能分析
- 提供基于 Win32 的简易界面，支持选择两个 .bin 文件并导出合并后的文件。
- 合并逻辑固定为：第 1 个文件读取到 4KB，不足部分以 0xFF 填充后写入输出文件。
- 第 2 个文件内容按原始顺序追加到输出文件末尾，最终生成 merged.bin（或用户指定路径）。
- 关键流程包括文件选择、保存路径确认、二进制读写与合并完成提示。
